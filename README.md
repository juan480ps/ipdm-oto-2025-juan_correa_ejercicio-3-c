🧭 Cuadrante de Compose
Esta aplicación es parte de los ejercicios prácticos para reforzar los conocimientos adquiridos sobre Jetpack Compose. En este proyecto, se crea una interfaz que divide la pantalla en cuatro secciones iguales, cada una destacando una función composable (Text, Image, Row y Column) con su respectiva descripción.​

Durante el desarrollo, se aplican conceptos clave de Compose, como:

    Uso de Row y Column para estructurar la disposición de los cuadrantes.

    Aplicación del modificador Modifier.weight() para distribuir el espacio equitativamente entre las secciones.

    Estilización de texto con propiedades como fontWeight y textAlign.

    Asignación de colores de fondo distintos a cada cuadrante para mejorar la visualización.​

Este ejercicio ayuda a consolidar la comprensión de cómo estructurar y estilizar componentes en Compose, enfocándose en la disposición y presentación de elementos visuales y textuales.
